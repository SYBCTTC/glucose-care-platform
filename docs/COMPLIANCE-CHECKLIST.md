# 等保三级技术自查清单（设备与人员管理平台）

> 说明：本清单为技术实现侧的落地项，**最终以院方信息安全与法务要求为准**。
> 每次发布前逐项确认，未完成项不得进入生产环境。

## 1. 身份鉴别

| 项 | 落地位置 | 状态 |
|---|---|---|
| 密码 ≥ 8 位且含字母+数字 | `auth.dto.ts` 登录与改密 schema | 已实现（策略细节待院方确认） |
| 登录失败 5 次锁定 30 分钟 | `AuthService.login`（基于审计日志统计） | 已实现 |
| 会话空闲 30 分钟登出 | 前端 `BasicLayout` + 后端 `JWT_EXPIRES_IN` | 已实现 |
| 密码定期更换提醒 | 依赖 `User.passwordChangedAt` | 待实现 |
| 双因子（口令 + 短信/OTP/UKey） | — | 待院方确认后实现 |

## 2. 访问控制

| 项 | 落地位置 | 状态 |
|---|---|---|
| 角色与权限点分离 | `packages/shared/src/dict/roles.ts` | 已实现 |
| 接口级权限校验 | `PermissionsGuard` + `@RequirePermissions` | 已实现 |
| **数据行级权限（本科室）** | `scope.util.assertInScope` / `buildScopeWhere` | 已实现（新增接口必须复用） |
| 默认拒绝 | `JwtAuthGuard` 全局生效 | 已实现 |
| 越权访问拒绝并留痕 | `AuditLogInterceptor` 写 `DENIED` | 已实现 |
