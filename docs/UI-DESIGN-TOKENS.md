# 前端视觉与样式规范（v1 · 已生效）

> **状态：已填写并落地。**
>
> - 院方 VI 主色 `#6ad3d8`（医疗青），**支持暗色模式**，其余项采用推荐默认（下表已标注"采用默认"）。
> - 已生成：`apps/web/src/styles/{tokens.ts,global.css,chartTheme.ts}`、`apps/web/src/store/theme.ts`。
> - 已写入 AI 强制规则：`.codebuddy/rules/ui-design-tokens.md`（页面禁止硬编码色值、新增语义色须先登记）。
>
> **技术处理说明（重要）**：`#6ad3d8` 与白字对比度仅 **1.76:1**（WCAG AA 要求 4.5:1），
> 因此主按钮/主色标签文字改用深墨色 `#08333a`（对比度 **11.9:1**），
> 主色本身保留用于链接、选中态、图表主序列；正文链接压暗为 `#1f8f96`，hover/active 为 `#57c7cd` / `#41a9af`。
>
> 颜色统一用 **HEX（`#RRGGBB`）**，需要透明度另填 RGBA 或标注透明度百分比。

## 5. 业务语义色（本项目特有，重要）

### 5.1 血糖监测结果（动态字典 `GLUCOSE_RESULT`，代号 DY-RESULT）

> 色值存放于数据库 `DictItem.color`（由 seed/后台维护），前端直接取用，**不写进 `tokens.ts`**；
> 本节即色值登记处，改色先改本节再改数据。取值清单见 `docs/COMMON-DATA.md` 的 `DY-RESULT`。

| 语义               | code | 展示     | 颜色      | 判定方式 / 是否可选                           | 计入统计 |
| ------------------ | ---- | -------- | --------- | --------------------------------------------- | -------- |
| 偏低（数值落区）   | `0`  | 具体数值 | `#4BB2ED` | 后台判定：< 3.9 mmol/L；**不进录入选项**      | 是       |
| 正常（数值落区）   | `1`  | 具体数值 | `#389E0D` | 后台判定：3.9 ~ 16.7 mmol/L；**不进录入选项** | 是       |
| 偏高（数值落区）   | `2`  | 具体数值 | `#FF1516` | 后台判定：> 16.7 mmol/L；**不进录入选项**     | 是       |
| Low（极低，类型）  | `3`  | `Low`    | `#4BB2ED` | 仪器读数 < 0.6 mmol/L；手选类型               | 是       |
| High（极高，类型） | `4`  | `High`   | `#FF1516` | 仪器读数 > 33.3 mmol/L；手选类型              | 是       |
| 拒检               | `5`  | 拒检     | `#3C3C3C` | 手选                                          | 否       |
| 外出               | `6`  | 外出     | `#3C3C3C` | 手选                                          | 否       |
| 请假               | `7`  | 请假     | `#3C3C3C` | 手选                                          | 否       |
| 已吃饭             | `8`  | 已吃饭   | `#3C3C3C` | 手选                                          | 否       |
| 未进食             | `9`  | 未进食   | `#3C3C3C` | 手选                                          | 否       |

约定：

- **色 + 文双通道**：只靠颜色区分不满足可访问性，标签文字（`label`）必须与颜色同时展示。
- **偏低/偏高 ≠ Low/High**：前者是"数值落在低/高区间"（后台按阈值自动判定），后者是"检测结果类型本身为极低/极高"（由仪器读数或人工指定），二者同色是表示同一方向，**禁止互相替代**。
- 录入界面只渲染 `checkable=true` 的项（`0`/`1`/`2` 由后台按阈值判定，均不出现在选项里），统计口径按 `counted` 过滤。
- 录入界面的「检测」是**占位选项**（`GLUCOSE_ENTRY_DETECT = 'DETECT'`，仅入参用）：选中它表示"这次有真实读数"，填血糖值后由后台判定为 `0`/`1`/`2`；它不属于本字典，也不入库。
- 阈值线（ECharts markLine）颜色同语义色：低 `#4BB2ED`、高 `#FF1516`。
- 目标范围内（TIR，CGM 预留）：`#52C41A`（采用默认），markArea 8% 底。

## 16. 命名与落地约定（我会按下述规则生成，可修改）

| 类别         | 前缀           | 示例                                                      |
| ------------ | -------------- | --------------------------------------------------------- |
| 颜色变量     | `--gc-color-`  | `--gc-color-glucose-low`                                  |
| 间距         | `--gc-space-`  | `--gc-space-md`（8px）                                    |
| 圆角         | `--gc-radius-` | `--gc-radius-md`（6px）                                   |
| 阴影         | `--gc-shadow-` | `--gc-shadow-card`                                        |
| 字号         | `--gc-font-`   | `--gc-font-md`（14px）                                    |
| 层级 z-index | `--gc-z-`      | 内容 1 / 吸顶 100 / 抽屉 1000 / Modal 1010 / Message 1020 |

**强制约定（后续开发必须遵守）**

1. 页面内**禁止硬编码色值**，一律用 CSS 变量或 Antd token。
2. 业务语义色（血糖区间、状态、设备）只能引用第 5 节定义的变量，不得临时造色。
3. 新增语义色必须**先登记到本文件**，再写代码。
4. 表格数值统一 `font-variant-numeric: tabular-nums`，右对齐。
5. 状态表达必须"色 + 文"双通道（如低血糖：红色 + "低"标签 + 下箭头图标）。
